# MuslimApps 🕋

MuslimApps adalah aplikasi Android modern yang dibangun menggunakan **Jetpack Compose** untuk membantu umat Muslim dalam menjalankan ibadah sehari-hari. Aplikasi ini menggabungkan desain UI/UX yang indah dengan fitur fungsional yang lengkap.

## ✨ Fitur Utama

- **🕌 Jadwal Shalat & Adzan**: Waktu shalat akurat berdasarkan lokasi GPS pengguna disertai notifikasi pengingat Adzan.
- **📖 Al-Quran Digital**: Baca Al-Quran lengkap dengan teks Arab, Terjemahan Indonesia, dan pemutar Audio (Murottal) per ayat oleh Syeikh Mishary Rashid Al-Afasy.
- **🧭 Kompas Kiblat**: Temukan arah Ka'bah secara akurat menggunakan sensor orientasi perangkat.
- **📿 Tasbih Digital**: Penghitung dzikir interaktif dengan fitur getar dan target hitungan.
- **💰 Kalkulator Zakat**: Hitung zakat maal Anda dengan mudah berdasarkan nishab emas terkini.
- **📍 Lokasi Masjid**: Cari masjid terdekat di sekitar Anda melalui integrasi Google Maps.
- **🙏 Daftar Doa Harian**: Kumpulan doa-doa harian lengkap dengan teks Arab, Latin, dan artinya.
- **🌓 Mode Gelap/Terang**: Dukungan tema aplikasi yang dapat disesuaikan secara manual.
- **🔖 Bookmark**: Menyimpan otomatis surah terakhir yang dibaca untuk dilanjutkan kembali.

## 🚀 Teknologi yang Digunakan

- **Kotlin**: Bahasa pemrograman utama.
- **Jetpack Compose**: Untuk membangun UI deklaratif yang modern.
- **Retrofit & GSON**: Untuk mengambil data dari API (Prayer Times & Al-Quran).
- **AlarmManager**: Untuk penjadwalan notifikasi Adzan.
- **Fused Location Provider**: Untuk mendapatkan koordinat lokasi GPS.
- **Lottie Files**: Untuk animasi yang halus dan interaktif.
- **Material Design 3**: Standar desain UI terbaru dari Google.

## 🛠️ Cara Menjalankan Project

1. Clone repository ini:

2. Buka project di **Android Studio (Ladybug atau versi terbaru)**.
3. Sinkronkan Gradle dan pastikan semua dependensi terunduh.
4. Jalankan aplikasi di Emulator atau perangkat fisik Android.
